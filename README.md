## About

I am a **Bachelor of Information Technology student currently in my 6th semester**, focused on developing strong foundations in software engineering, full-stack development, quality engineering, automation, cloud technologies, and applied AI/ML.

My engineering approach is centered around building software that is **maintainable, testable, secure, scalable, and aligned with real product requirements** rather than simply making applications work.

I am actively developing experience across the software lifecycle — from requirements and system design to implementation, API integration, automated testing, CI/CD, database engineering, deployment, and continuous improvement.

My current technical direction combines:

* **Software Engineering** — clean architecture, modular development, OOP, reusable components, maintainability
* **Full-Stack Development** — modern frontend development, backend APIs, databases, authentication, and integration
* **Quality Engineering** — Playwright, API testing, Postman/Newman, JMeter, functional and performance testing
* **DevOps & Automation** — Git, GitHub, GitLab, Jenkins, CI/CD workflows, environment configuration
* **AI / ML & Data** — Python foundations, machine-learning concepts, data analysis, and intelligent application development
* **Product Engineering** — transforming requirements into practical, user-focused and technically sustainable systems

### Open To

`Software Engineering Internships` · `QA / Automation Internships` · `Full-Stack Development` · `Junior Software Engineering` · `AI/ML Projects` · `Open Source Collaboration` · `Technical Projects`
